# 薄技能依赖约束

本技能是**薄技能**：只出 Qt / Qt Quick 框架层的判据，能力经声明获取，不内嵌他技能正文。

## 规则

1. 所有外部能力必须在 [`dependence/dependence.md`](../../dependence/dependence.md) 与
   `deps.json` 中声明；未声明的能力不得调用。
2. 禁止把其他技能的正文、清单或知识文件复制进本目录（内嵌即视为越权）。
3. 禁止直接 `import` 他技能模块；跨技能只传「意图 + 参数」，由对方在其目录内执行。
4. 转派边界：视觉/交互 → `ui-design`；SQL 与数据源 → `database-management`；
   并发架构 → `concurrency-design`；C++ 语言级 → `cpp-expert`；Python 语言级 → `python-expert`。
5. 每条依赖必附 `source_url`（GitHub/GitLab/官方仓库或发布页原始链接；本地技能 `local://<id>`）；
   缺 `source_url` 即判不合格，`knowledge_index.py --check-deps` 报错退出。
6. 依赖缺失：记过程链中断并报告缺项，禁止伪造能力继续。
7. 增删依赖须走 [update 接口](../../update/update.md) 并记 CHANGELOG。

## 违规后果

- 内嵌他技能正文：对方更新后本技能判据陈旧，给出矛盾建议且无法追溯；
- 缺 source_url：依赖不可复现，安装端无法同检同净化；
- 越界 import：跨技能耦合，单技能无法独立停用或迁移。
