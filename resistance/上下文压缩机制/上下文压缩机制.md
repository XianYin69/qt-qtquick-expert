# 上下文压缩机制

规定长任务里如何压缩中间产物，避免上下文溢出导致丢判据。

## 规则

1. 探针原始输出**只保留摘要行**（退出码 + 疑点计数 + 前 N 条命中），全文落 tmp 文件。
2. 多叶评审时逐叶压缩：每叶只留「命中条目 + 出处」，未命中叶记一行「无命中」。
3. 长文档取证：取回正文先摘要（≤300 字）再引用，禁止整篇粘进对话或本体。
4. 逻辑链是压缩后的权威载体：每条判断只留「证据→结论→取舍→边界」四要素。
5. 需要回溯细节时用路径引用（`tmp/<文件>`），不用文本复述。
6. 压缩不得丢分级：blocking 条目及其出处必须原样保留。

## 触发条件

- 单轮输出接近上限；
- 一次任务涉及 ≥3 个叶；
- 探针输出行数 > 200。

## 违规后果

- 压缩丢出处：判据退化为无来源断言，等同臆造；
- 不压缩直接堆原文：上下文溢出，后续步骤基于残缺历史做判断。
