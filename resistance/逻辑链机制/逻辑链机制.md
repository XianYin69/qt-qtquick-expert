# 逻辑链机制

规定决策如何留痕，使每条判断可追溯、可复核、可反驳。

## 规则

1. 每个决策节点记一条：`证据 → 结论 → 取舍 → 边界`（四要素缺一即视为未记录）。
2. 证据必须可指认：探针输出摘要、官方文档页名、或用户原文片段。
3. 取舍必须写明**被放弃的方案**及其代价（例：放弃 `Repeater` 因数据量 >1k）。
4. 边界必须含版本口径（Qt 6.x / Qt 5.15）与栈（Widgets / Quick / 绑定层）。
5. 审查节点跑正反双链辩论：先铺 pro/con 论据清单，再记裁决；裁决仅供参考，最终判断在本节点。
6. 高危结论（许可合规、ABI、跨线程销毁、静态链接）必须额外记「出处原文标题」。
7. 链条只增不删：修正以新条目引用旧条目，不得抹掉历史。

## 用途

- 用户质疑结论时，沿链回溯到证据即可复核；
- 判据过时时（Qt 版本变更），按链定位受影响条目再更新叶文件。

## 违规后果

- 无链结论：无法复核，错误会沉淀进知识树并被后续回答继承；
- 抹历史：回滚与责任定位失效。
