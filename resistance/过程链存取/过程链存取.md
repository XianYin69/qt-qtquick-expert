# 过程链存取

规定流程状态的记录、中断与恢复，保证跳步可被发现。

## 规则

1. 每进入一个节点记一条 `step`（节点名 + 时间 + 输入摘要）。
2. 审查/校验失败即记 `interrupt`：失败项、错误签名、已试次数、下一步修复方案。
3. 修复后 `resume`：从被中断节点继续，**不得跳到下游节点**收尾。
4. 任一路径完成即收口返回调度方整合续排：本技能完成不等于整段任务完成。
5. 中断与恢复都必须可指认证据（脚本退出码或输出片段）。
6. 过程链落用户缓存目录或 `tmp/`，**不得写入 skill 目录**（与垃圾回收机制一致）。

## 存取格式（要点）

| 字段 | 含义 |
|---|---|
| `step` / `node` | 当前节点名（与 `branch/流程/` 文件夹名一致） |
| `status` | running / done / interrupt / resume |
| `evidence` | 探针输出摘要或退出码 |
| `error` | 错误签名（同类错误计数用） |
| `retry` | 已试次数（达 10 触发熔断） |

## 违规后果

- 不记中断：修复过程不可见，同一错误被反复重试至熔断；
- 跳步收尾：交付缺段（边界/未覆盖丢失），判据不可复现。
