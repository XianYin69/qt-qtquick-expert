# 沙盒机制

规定未指定目标工作目录时的作业位置与交付方式。

## 规则

1. 用户/调度方**未指定目标目录**时，在固定路径建沙盒作业（工作区 `tmp/` 或 `SMS_TMP`），
   不得就地写入任何技能目录。
2. 沙盒内完成全部生成与校验（悬空链接、行数、依赖清单、脚本编译）。
3. 交付：询问目标路径后复制/释放到目标 skill 目录；无目标路径则保留沙盒并报告位置。
4. 交付成功后删除沙盒过程工件；未交付不得污染本体。
5. 沙盒创建失败：降级为纯 tmp 镜像作业，收尾时说明交付受阻原因。
6. 附属/私有内容不得进公开沙盒产物（与 git 工作流约束第 11 条双仓模型一致）。

## 沙盒结构（与本体同构）

```
tmp/<skill-id>/
  SKILL.md  agent/  asset/  branch/  dependence/  references/
  resistance/  scripts/  planned_tasks/  update/  tmp/
```

## 违规后果

- 直写技能目录：绕过审查，本体进入不可回滚的半完成态；
- 沙盒残留：过程工件污染下次任务，且可能泄漏用户路径信息。
