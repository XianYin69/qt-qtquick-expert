# i18n-a11y — 国际化、高 DPI、键盘与无障碍

## 判据要点

- 可翻译文本必须走 `tr()`（C++）/ `qsTr()`（QML）/ `QCoreApplication::translate("Ctx","x")`（跨类）。
  拼接字符串破坏翻译（语序因语言而异）：用 `%1` 占位 + `arg()`。
- 复数：`tr("one file","%n files",count)`（`%n` 由 Qt 按语言规则展开）；
  自己写 `count>1?"s":""` 在俄语/波兰语等复数类别下必错。
- 流程：`lupdate` 抽 `.ts` → 翻译 → `lrelease` 出 `.qm` → `QTranslator::load` →
  `installTranslator`。`.qm` 必须随包部署（`windeployqt` 默认可能跳过 translations，须核对）。
- 运行时切换语言：重装 translator 后须让界面重取文本——`retranslateUi()` 或
  触发 `QEvent::LanguageChange`；QML 侧 `qsTr` 依赖 `retranslate()`，不会自动全量刷新。
- RTL：`setLayoutDirection()` 之外，QML 用 `LayoutMirroring.enabled`（Qt 5.11+/Qt6）；
  手写 `anchors.left` 的界面在 RTL 下不会镜像，须用 `start/end` 语义。
- 高 DPI：Qt6 默认启用缩放，取整策略改 `QGuiApplication::setHighDpiScaleFactorRoundingPolicy()`
  **且必须在构造 app 对象之前**；混合 DPI 多屏须测整数与非整数缩放两档。
  位图资源用 `@2x` 或 SVG；字体用 pointSize 不用 pixelSize。
- 键盘：所有可交互控件须有 `focusPolicy` 与 `Tab` 顺序（`QWizard`/`setTabOrder`）；
  快捷键走 `QKeySequence` 标准端口（`QuitRole`/`OpenRole`），别硬编码 `Ctrl+`——macOS 应映射 Command。
- 无障碍：Qt 暴露 `QAccessible` 接口；QML 用 `Accessible.role/name/description` 附加属性，
  自定义 `QQuickItem` 须实现 `QAccessibleInterface` 或至少给 `Accessible.name`。
  仅靠颜色区分状态 = 无障碍缺陷（须有文本/形状冗余）。
- PyQt/PySide 注记：`tr()` 在 Python 侧同样有效，但 `.ts` 抽取须用 `pyside6-lupdate`。

## 取证

`python -B scripts/migration_probe.py --dir <proj>`（查 Qt5 遗留 DPI 属性）；
`QT_LOGGING_RULES="qt.qpa.*=true"` 看 DPI 报告；无障碍用 NVDA（Windows）/VoiceOver（macOS）实读。

## 边界

文案质量与本地化商务不在本叶；视觉可达性细则转派 `ui-design`。
