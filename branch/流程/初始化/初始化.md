# 初始化

两条路径的共同前置步骤：建立工作空间与许可基线。

## 动作

1. 确认目标目录；未指定时固定路径沙盒作业（`resistance/沙盒机制`）。
2. 建立 `tmp/` 工作镜像：生成文件一律入 tmp，禁止直写 skill 目录。
3. 写入 MIT `LICENSE`（工作区根与 tmp 各一份，已有不覆盖）。
4. 检查仓库：无 `.git/` 即 `git init`（不得跳过）；核对 `.gitignore` 含 `tmp/` 与 IDE 目录。
5. 建立 `planned_tasks/`（`README.md` + `template.json`，已有不覆盖）。
6. 挂载五大机制：逻辑链、过程链、上下文压缩、垃圾回收、惩罚。
7. 依赖自检：`python -B scripts/knowledge_index.py --check-deps`。

## 产出

- `LICENSE`、`.gitignore`、`planned_tasks/`、功能分支 `feature/init`、逻辑链首条。

## 兜底

- 依赖缺失：记过程链中断（interrupt）并报告缺项，禁止伪造能力继续。
- 沙盒创建失败：降级为 tmp 镜像作业，收尾时询问交付路径。
- 无 Qt 工具链：不阻断初始化，取证探查阶段按 `[本地]` 降级。
