# 评审清单

按叶输出可勾选的分级清单，作为交付的骨架。

## 动作

1. `python -B scripts/review_checklist.py --leaf <叶>` → 取该叶全部条目与分级计数。
2. 全项目评审：不带 `--leaf`，按九叶顺序输出并汇总 `blocking/major/minor/verify` 计数。
3. 用探针结果**回填**条目状态：命中疑点的条目置为「已命中」，未取证的保持未勾选。
4. 删除与本次问题无关的条目时，须在「未覆盖」段说明删了哪类、为什么。
5. 每条保留出处标注（`[文档名]` 或 `[本地]`），不得留无出处条目。

## 产出

- 分级清单（含命中状态与计数），作为「输出交付」的清单段。

## 兜底

- 清单文件缺失：记过程链中断，先补 `asset/checklists/<叶>.md` 再续。
- 条目与实测矛盾：以实测为准，条目改标 `[本地]` 并回写叶文件（经 `update/` 通道）。
