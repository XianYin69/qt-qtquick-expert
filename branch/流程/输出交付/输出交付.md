# 输出交付

组装五段式交付文本；缺任一段即判不合格。

## 动作

`python -B scripts/advice_compose.py --leaf <叶> --verdict ... --basis ... --evidence ... \
--scope ... --gaps ...`

| 段 | 内容 | 硬要求 |
|---|---|---|
| 结论 | 一句话可执行判断 | 不含糊，不并列两个答案 |
| 依据 | 官方文档条文 / 标准 / 实测输出 | 每条带出处标注 |
| 取证 | 可复现命令与原始输出摘要 | 未运行的不得写「已验证」 |
| 边界 | Qt 版本区间、栈、平台、前提假设 | 假设必须显式写出 |
| 未覆盖 | 未验证项、转派项、被删条目 | 不得留空 |

## 产出

- 交付文本 + 分级清单 + 探针输出摘要。

## 兜底

- 任一段为空：脚本返回 1，本步判不合格，记过程链中断后回上游补齐。
- 用户只要简短答案：仍须保留「结论 + 边界」两段，其余压缩为一句。
