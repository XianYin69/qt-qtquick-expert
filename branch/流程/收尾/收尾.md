# 收尾

交付后清理与版本落账；本步完成即顾问路径结束。

## 动作

1. 悬空链接校验：`python -B scripts/check_links.py --root .` → 必须为 0。
2. 行数与长行红线：所有 `.md` ≤ 50 行；脚本无 >100 字符行、无裸 `except`。
3. 依赖自检：`python -B scripts/knowledge_index.py --check-deps`（每条必附 `source_url`）。
4. 双链辩论：对本次关键结论跑 pro/con，裁决记入逻辑链。
5. 垃圾回收：`tmp/` 过程工件释放到目标目录后删除；缓存不得留在 skill 目录。
6. git：功能分支提交 → 审核通过合 `dev` → 整体审查通过 `dev` 合 `main`；
   **推送前须用户确认**，未确认不得 `git push`。
7. 计划任务：核对 `planned_tasks/` 声明有效（本技能不自行执行，到期交 SMS 调度器）。

## 产出

- `main` 分支上的本地提交、CHANGELOG 条目、清理后的目录。

## 兜底

- 悬空链接非 0：回上游修链接，禁止用删除引用文件的方式「消链接」。
- 审查失败重试达 10 次：熔断，回退功能分支或求助用户。
