# 修改流程（独立路径）

修改本技能自身内容时走这条路径，与顾问路径互不交织；结束后标记「完成项目修改」。

## 动作

1. 明确修改对象与理由（新增判据 / 修链接 / 调叶结构 / 改脚本）。
2. 全部变更先落 `tmp/` 镜像，**禁止直写 skill 目录**（唯一写盘通道见
   [update 接口](../../../update/update.md)）。
3. 比对：`update/` compare 出差异清单，确认无越界文件（不得触碰其他技能目录）。
4. 释放：compare 通过后 release 到目标目录。
5. 校验：`check_links.py` 悬空为 0；`.md` ≤ 50 行；脚本无长行与裸 `except`；
   `knowledge_index.py --check-deps` 通过。
6. 记 `CHANGELOG.md`（含违规后果），git 功能分支提交 → 审核通过合 `dev`。

## 禁止

- 不得删除 `resistance/` 下任何约束文件。
- 不得把 `[本地]` 条目改标 `[联网]` 而不附确证链接。
- 不得在修改路径中顺带回答顾问问题（两条路径各自收口）。

## 兜底

- compare 发现越界文件：丢弃该变更并记过程链中断，报告越界路径。
- 校验失败重试达 10 次：熔断，回退本次修改。
