# 专家判断

把证据收敛成一句可执行结论，四要素缺一不可。

## 动作

1. **证据**：探针输出 / 官方文档条文 / 用户原文，三者至少其一。
2. **结论**：一句话判定「可以 / 不可以 / 在 X 条件下可以」，不含糊。
3. **取舍**：说明放弃了哪个替代方案及其代价（如 Loader vs Repeater）。
4. **边界**：版本区间（Qt 6.x / Qt 5.15）、栈（Widgets / Quick / 绑定层）、平台（桌面/Android/iOS）。
5. 决策岔路先跑正反双链自辩（`logic_chain debate`），修正路径后再定稿；
   高危结论（许可合规、ABI、跨线程销毁）必须引官方页原文标题，不得只凭常识。

## 分级规则

- `blocking`：有权威依据或可复现缺陷（崩溃、数据竞争、许可不成立、契约破坏）。
- `major`：明确代价但可运行（性能塌陷、绑定打断、部署缺项）。
- `minor`：风格与可读性——**只作建议，不得标 blocking**。
- 偏好不得升格为判据；无出处的判据只能标 `[本地]` 并降一级。

## 产出

- 逻辑链条目：证据 → 结论 → 取舍 → 边界；以及分级后的判断列表。

## 兜底

- 证据与文档冲突：以文档为准，把冲突记入逻辑链并标为待复核。
- 无法定级：输出「条件式结论」+ 取证命令，交回用户实测。
