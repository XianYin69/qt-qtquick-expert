# 流程（Process）

本目录存放 qt-qtquick-expert 的执行流程细则，每步独立成文件夹（文件夹名=流程名）。

## 顾问路径（主路径）

```
[初始化/](初始化/初始化.md) → [问题解析/](问题解析/问题解析.md) → [领域定位/](领域定位/领域定位.md) →
[知识检索/](知识检索/知识检索.md) → [取证探查/](取证探查/取证探查.md) → [专家判断/](专家判断/专家判断.md) →
[评审清单/](评审清单/评审清单.md) → [重构建议/](重构建议/重构建议.md) → [输出交付/](输出交付/输出交付.md) →
[收尾/](收尾/收尾.md) → 完成
```

横切节点 [浏览器学习/](浏览器学习/浏览器学习.md)：任一步遇到不明白的 API、语法或版本行为，
强制先派 `file_ops` 联网取证并给出出处，再回原节点继续。

## 修改路径

```
[初始化/](初始化/初始化.md) → [修改流程/](修改流程/修改流程.md) → 完成
```

修改路径独立运行，结束后标记「完成项目修改」，不接在收尾之后。

## 步骤列表

| 步骤 | 路径 | 说明 |
|---|---|---|
| 初始化 | [`初始化/`](初始化/初始化.md) | 工作空间、MIT、git、机制挂载（两条路径共同前置） |
| 问题解析 | [`问题解析/`](问题解析/问题解析.md) | 输入/输出/Qt 版本/绑定层/验收标准 |
| 领域定位 | [`领域定位/`](领域定位/领域定位.md) | `classify_topic.py` 映射到知识树叶，或转派专项 |
| 知识检索 | [`知识检索/`](知识检索/知识检索.md) | 取叶细则与清单，缺项即触发浏览器学习 |
| 取证探查 | [`取证探查/`](取证探查/取证探查.md) | 跑探针脚本，无工具即降级并标 `[本地]` |
| 专家判断 | [`专家判断/`](专家判断/专家判断.md) | 证据→结论→取舍→边界，落逻辑链 |
| 评审清单 | [`评审清单/`](评审清单/评审清单.md) | 按叶输出 blocking/major/minor |
| 重构建议 | [`重构建议/`](重构建议/重构建议.md) | 可执行改法（默认只读，改动须显式授权） |
| 输出交付 | [`输出交付/`](输出交付/输出交付.md) | 五段交付（结论/依据/取证/边界/未覆盖） |
| 收尾 | [`收尾/`](收尾/收尾.md) | 垃圾回收、git、tmp 释放 |
| 修改流程 | [`修改流程/`](修改流程/修改流程.md) | 修改本技能内容（经 update/ 通道） |

## 全局机制

各步骤接入 `resistance/` 五大机制（垃圾回收、上下文压缩、逻辑链、过程链存取、惩罚）；
依赖能力见 [dependence/](../../dependence/dependence.md)。
