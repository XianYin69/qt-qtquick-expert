# 知识检索

取主叶的细则与评审清单，缺项即补，不明即联网。

## 动作

1. `python -B scripts/knowledge_index.py --leaf <叶>` → 取 title/probes/cites 与两份文件路径。
2. 读 `asset/knowledge/<叶>.md` 取判据要点；读 `asset/checklists/<叶>.md` 取分级判据。
3. 核对叶内 `cites` 的出处是否覆盖当前问题版本口径（Qt6 / Qt5 遗留 / PySide6）。
4. 判据缺失或版本行为不确定 → 派 `file_ops` 检索官方页，取回后按
   [参考书目](../../../references/参考书目/参考书目.md) 规则标 `[联网]` 或 `[本地]`。
5. 新取到的可靠判据回写叶文件（经 `update/` 通道，先入 tmp），并记 CHANGELOG。

## 产出

- 判据集合（每条带出处标注）+ 使用的探针清单。

## 兜底

- 叶文件缺失：立即记过程链中断，先补叶再续，禁止跳过判据直接下结论。
- 官方页不可达：条目降级为 `[本地]`，并在「未覆盖」段声明未确证。
