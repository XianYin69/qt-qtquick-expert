# 领域定位

把问题映射到知识树叶（九叶），或判定应转派专项技能。

## 动作

1. `python -B scripts/classify_topic.py "<问题文本>"` → 取排名前三的叶与命中关键词。
2. 未命中任何叶 → 触发横切节点 [浏览器学习](../浏览器学习/浏览器学习.md)，禁止凭记忆作答。
3. 命中多叶时按**判据顺序**定主次：正确性 → 线程/所有权 → 契约（元对象/模型）→ 性能 → 风格。
4. 判定转派：视觉/交互规范 → `ui-design`；SQL 与数据源 → `database-management`；
   并发架构（锁粒度、线程池规模）→ `concurrency-design`；
   纯 C++ 语言问题 → `cpp-expert`；纯 Python 语言问题 → `python-expert`。
5. 转派时只传「意图 + 参数」，本技能仍负责 Qt 框架层判据的整合。

## 产出

- 主叶 + 次叶列表（含命中词），写入逻辑链；转派项记入「未覆盖」段。

## 兜底

- 分类得分并列：取优先级数字更小者为主叶，另一叶列为次叶。
- 问题横跨全部九叶（如整体架构评审）：改为逐叶跑评审清单，不做单叶结论。
