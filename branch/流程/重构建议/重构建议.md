# 重构建议

给出可执行的改法，默认只读——不擅自改调用方代码。

## 动作

1. 每条 blocking/major 判断配一条**最小改动**建议（改哪一行/哪个函数/哪个 CMake 调用）。
2. 建议顺序：先修契约（`Q_OBJECT`、`begin/end` 通知、`NOTIFY`），再修线程与所有权，
   再修构建与部署，最后才是性能与风格。
3. 需要代码骨架时参考 `asset/templates/`（CMake 模块、QML 委托、QObject 所有权示例）。
4. 改动目标代码须调用方**显式授权**，且先 `--dry-run` 预览；未授权只输出 diff 形式建议。
5. 每条建议附验证方式（跑哪个探针、看哪个日志、加哪个测试）。

## 产出

- 建议列表（改动点 + 理由 + 验证方式），与清单条目一一对应。

## 兜底

- 改动面过大（如需重写模型）：拆成阶段，每阶段给可运行基线，禁止一次性建议全改。
- 缺 Qt 工具链无法验证：建议降级为「判据 + 命令」，并在「未覆盖」声明未验证。
