# 取证探查

用脚本拿到可复现事实；没有事实就只能给「判据 + 命令」，不得写「已验证」。

## 动作

按主叶选择探针（`asset/knowledge_tree.json` 的 `probes` 字段）：

| 探针 | 取证对象 | 对应叶 |
|---|---|---|
| `env_probe.py` | qmake / CMake / qmllint / windeployqt / PySide6 / PyQt6 | 全部（前置） |
| `moc_probe.py` | 缺 `Q_OBJECT`、Q_OBJECT 落在 .cpp | object-model-meta |
| `qml_lint.py` | `qmllint` 实跑或静态疑点 | qtquick-qml / models-view |
| `build_probe.py` | `qt_add_qml_module`、AUTOMOC、链接可见性 | build-deploy |
| `deploy_probe.py` | `windeployqt --dry-run` 与插件缺项 | build-deploy |
| `perf_probe.py` | 场景图不友好写法 | rendering-performance / widgets-ui |
| `migration_probe.py` | Qt5 遗留 API 与移除项 | testing-migration / i18n-a11y |

调用形式：`python -B scripts/<探针>.py --dir <项目目录>`（部署类用 `--target <exe>`）。

## 产出

- 探针原始输出（含退出码）+ 疑点计数，写入逻辑链的证据节点。

## 兜底

- 工具缺失（退出码 3）：降级为静态判据，全部标 `[本地]`，并给出用户可自行执行的命令。
- 输出为空：不得推断为「无问题」，须写明「未覆盖」并建议实跑构建/测试。
- 同一探针连续失败达 10 次：触发惩罚熔断，回退或求助用户。
